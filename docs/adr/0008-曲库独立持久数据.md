# 曲库是独立持久数据，内置清单只做初始种子

**状态：已采用**

公司需要快速查询“哪些歌在抖音不能播放”，并且在后续收到新表时继续更新。我们决定把曲库作为独立数据文件保存在用户目录，内置 1,253 首去重歌曲作为首次初始化种子；用户导入的 XLSX/CSV 会合并到本地曲库，不直接改写安装包，也不依赖 Excel。
曲库同时支持运营自建文件夹，按主播或使用场景组织歌曲；上传的音频文件复制到用户目录下对应文件夹，歌名清单保存在 `music-library.json`。内置禁播清单是系统文件夹，不允许删除或上传音频。
批量检测只把明确同名且同歌手的命中标为“不能播放”，同名但歌手不同或缺失标为“疑似禁播”，没有命中标为“未命中禁播库”并提示仍需平台复核。独立的“更新禁播歌曲”入口强制把文件写入系统禁播清单。

这样升级软件不会覆盖人工修改，后续导入也能持续累积；代价是每台电脑的曲库修改各自保存，需要共享更新时必须再导入同一份歌单文件。内置歌曲默认标记为“抖音无版权”，运营若确认可播放，可以手动改状态。
