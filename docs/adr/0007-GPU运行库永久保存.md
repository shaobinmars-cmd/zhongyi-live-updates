# GPU 运行库放在用户目录，不随软件升级覆盖

**状态：已采用**

CUDA 的 cublas/cudnn 约 2 GB，原先通过 pip 装进安装目录里的 `python-embed\Lib\site-packages\nvidia`。安装版升级会替换整个引擎目录，导致每次更新后都要重新下载。现在改为安装到 `%LOCALAPPDATA%\douyin-live-info\gpu-runtime`，转写进程把其中各 `nvidia\*\bin` 加入 DLL 搜索路径。

新安装器在覆盖旧版前自动把旧目录里的 GPU 库迁移到用户目录；新版 App 第一次安装/校验 GPU 时也兼容迁移旧库。这样升级只替换程序，CUDA 库长期保留。代价是 GPU 目录不再属于应用安装的一部分，用户重装系统或删除用户数据目录后仍需重新安装。
