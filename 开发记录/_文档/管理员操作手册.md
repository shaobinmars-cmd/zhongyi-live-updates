# 管理员操作手册

> 这个文件**不要发给运营**。运营只需要 `使用说明.md`。

项目目录：`H:\直播运营中控台`（指向真实项目路径的快捷目录，两边内容完全同步）

---

## 一、给运营签授权

1. 让运营打开软件，把激活页上的机器码复制发给你

2. **双击这个文件**（不用敲命令）：

   ```
   H:\直播运营中控台\tools\一键签发授权.bat
   ```

   它会依次问你三句：机器码、运营名字、到期日期（直接回车 = 一年后）。
   签完窗口里会直接告诉你文件在哪，还会问你要不要打开文件夹。

3. 发给运营：右键那个 json → 打开方式 → 记事本 → `Ctrl+A` 全选 → `Ctrl+C` 复制 →
   贴到微信发给运营，让他粘到激活页点「激活」。

**私钥 `tools\授权密钥\私钥.pem` 是你唯一的签发权，永远不要发给别人，也不要放进安装包。**

签出来的 `授权_*.json` 发完就可以删。但项目根目录里的 `授权.json`（没有下划线和名字的那个）
是你自己这台机器的管理员授权，别删。

## 二、随时停掉某个运营

生成吊销名单：

```
cd /d "H:\直播运营中控台"
set PATH=D:\APP\手机对接\.tools\node-v22.23.3-win-x64;%PATH%
node tools\签发授权.mjs --吊销 机器码1,机器码2 --输出 吊销名单.txt
```

把 `吊销名单.txt` 放到公司共享盘（或一个网址），然后在需要管控的机器上用记事本打开：

```
%APPDATA%\douyin-live-info\teardown.json
```

加上一行 `"revokeSource": "\\共享盘路径\吊销名单.txt"`（网址也行）。

程序每次启动会去读一次，名单里有这台机器的机器码就直接拒绝使用。
读不到（比如断网、共享盘连不上）就放行，保证正常办公不受影响。

> 局限说清楚：如果运营刻意断网且不去连那个共享盘，还是能继续用。
> 要做到"一点就停、无法绕过"，只有联网校验这一条路，那需要一台常开的服务端。

## 三、发新版

```
cd /d "H:\直播运营中控台"
set PATH=D:\APP\手机对接\.tools\node-v22.23.3-win-x64;%PATH%
npm run electron:build
```

产物在 `release\` 目录，两个 exe。改版本号在 `package.json` 的 `version` 字段。

打包后把新的 `release\` 里那两个 exe 覆盖到桌面转发文件夹
`C:\Users\Administrator\Desktop\众艺传媒-直播运营中控台\`，连同运营说明一起发出。

## 六、弹幕通道（2.3.1 改动，必看）

### 原理

旧版是自己算签名直连抖音推送接口——那个签名经常变，一变就变成「显示已连接、一条弹幕都没有」。
2.3.1 改成：App 自己开一个**看不见的浏览器窗口**打开直播间页面（透明度 0、不进任务栏、点不到），
旁听页面自己收到的弹幕推送帧再解码。页面怎么连、签名怎么算都不用我们管。

### 两个必须知道的点

1. **抖音只给已登录的网页端推弹幕。** 没登录时页面能连上，但一帧都不推。
   所以每个运营第一次用要在「弹幕」页点「立即登录抖音」扫码（登录态存在 App 自己的会话目录里，不碰他的浏览器）。
2. **窗口必须是「页面自己认为可见」。** 实测用 `show:false` 完全隐藏的窗口，页面根本不会去订阅推送流；
   现在用的是「创建即可见 + 立刻把不透明度设 0」。改这段代码时别把它改回 `show:false`。

另外：弹幕窗口会拦掉图片/视频/字体请求，所以不占带宽（实测连上推送流只靠接口和小量帧）。

### 出问题怎么查

| 现象 | 原因 | 处理 |
|---|---|---|
| 弹幕页顶部提示橙色、状态写“未登录抖音” | 没登录 | 点「立即登录抖音」扫码 |
| 状态写“登录已失效” | 登录态过期/被踢 | 点「更换账号」重扫 |
| 连上也登录了但没弹幕 | 先看该主播是否真没人发言；再看日志里有没有 `[DanmuTap] [调试]` | 开 `DANMU_DEBUG=1` 环境变量启动，会把每帧写进日志 |
| 想彻底重置弹幕环境 | — | 让运营关掉软件，删 `%APPDATA%\douyin-live-info\Partitions\douyin-danmu` 整个文件夹，重开重新登录 |

日志里的关键词：`[DanmuTap] 打开弹幕通道`（开了）、`弹幕窗口就绪`（页面加载完）、
`[调试] 帧 xxB 消息=n`（真的收到数据了）、`长时间无数据，刷新弹幕窗口`（自愈中）、`未登录抖音（或登录已失效）`（要人工登录）。

## 七、把你的 AI 分享给运营（一人一密钥 + 能看用量）

运营自己不用买 AI 账号，用你这台机器的就行。

### 你这台（服务器端）

1. 先确保「设置 → AI 分析」已经填好能用（接口地址 / 密钥 / 模型），点「测试连接」通过
2. 到「设置 → **分享给运营（你这台电脑当服务器）**」：
   - 打开「**开启共享**」（端口默认 57888，不够用再改）
   - 点「**加一个运营**」，输入名字（比如「小九九」）→ 会生成一串 `zy-` 开头的**专属密钥**
   - 点「**复制配置给他**」→ 直接微信发过去
3. 列表里就能看到**每个人的调用次数和 token 用量**（上游接口返回用量时才计 token；报错会写在名字下面）
4. 谁走了、临时停用，点「删除」那个密钥即可，不用动其它人

### 运营那边（客户端）

「设置 → AI 分析」里：接口地址 = `http://你的IP:57888/v1`，密钥 = 发给他那串，模型名随便填 →「测试连接」→「拆解」页点「AI 分析」。

### 几个必须知道的限制

| 事 | 说明 |
|---|---|
| **必须在同一个局域网** | 地址里的 IP 是你公司的内网地址（如 192.168.3.79），人不在公司/不在同一网就连不上。异地要另做云中转。 |
| **你这台要开着** | 运营的分析都是你这台在跑；关机/休眠他们就失败。建议设成不自动休眠。 |
| **Windows 防火墙** | 第一次开共享会弹窗问“是否允许”，要勾上「专用网络」允许，否则运营连不上。 |
| **分析是串行也行的** | 多个人同时用会排队在你这台上（接口自己处理并发），用量按密钥分开记。 |
| 密钥泄露 | 直接在列表里删掉那一把，重新生成一把给他。 |

### 外地/不在同一办公室的运营

他们连不上内网地址，得走公网。你这边的出口是电信宽带（实测公网 IP `223.11.206.3`，动态的，会变）。
但实测发现是**两层网络**：你的路由器上面还有一层光猫（路由器 WAN 是 `192.168.1.39`，光猫管理页 `http://192.168.1.1`，标题「中国电信智能网关」）。

设置页里点「**一键开放外网**」能自动把**你自己这台路由器**的端口开好；
剩下光猫那层需要人工做一次（多久只做一次）：

1. 点「**打开光猫/路由器设置页**」（默认 `http://192.168.1.1`），用光猫的管理员密码登录
   - 不确定密码：打 10000 号说“我要在光猫上做端口映射，请给我超级密码”，或者直接让他们把光猫改成**桥接模式**
2. 找「端口映射 / 虚拟服务器 / DMZ」这一项
3. 两种做法选一种：
   - **最简单**：把 `192.168.1.39`（你路由器的 WAN 地址）设为 **DMZ 主机**
   - 或者：把端口 `57888` 映射到 `192.168.1.39:57888`（协议 TCP）
4. 回设置页再点一次「**一键开放外网**」→ 地址框会显示 `http://公网IP:57888/v1`
5. 把这个地址 + 各自的密钥发给外地运营

> 公网 IP 是动态的，宽带重拨后会变。到时候再点一次「一键开放外网」看新地址，重新发一下就行。

### 以后新加运营（不用再改软件）

设置页里有一块「**给新运营发配置（以后加人就用这个）**」，三步：

1. 去 DeepSeek 官网 → API keys → 给这个人建一把新 key（建完只显示一次，立刻复制）
2. 在软件「设置」页把名字和这把 key 填进去 → 点「**生成并复制发给他**」
3. 把自动生成的那段话微信发过去 → 他在自己软件里粘一下「一键填好」就行

全程不用改软件、不用重新打包。外地运营也一样 —— 他用自己那把 key 直连 DeepSeek，不受办公室网络影响。


- 「**批量加（一行一个名字）**」：把十几个运营名字一次粘进去，一次性生成全部密钥
- 每个人那一行点「**复制配置给他**」→ 会生成一段 `ZYAI1|地址|密钥|模型` 的配置
- 运营在自己软件里点「**粘贴配置（一键填好）**」，整段粘进去 → 自动填好 + 自动测试连接
