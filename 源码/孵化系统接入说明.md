## 四、怎么用（一个主播一个页面）

孵化页 3 个标签：

| 标签 | 谁用 | 做什么 |
|---|---|---|
| **主播** | 运营（每天） | 上面一个**可搜索下拉**选主播 → 进入该主播的页面 → 填这一场 → 保存 |
| **运营考核** | 教研 / 老板 | 填月份 → 算分，只看三项（提交率 / 真实度 / 进步率） |
| **资产与课表** | 教研 | 导入 AI 报告里的资产与课表、导出 CSV/Excel（运营只读） |

### 主播页长什么样

```
[ 选主播：输入名字搜索 ▾ ]  [ 只看我带的主播：填你的名字 ]  [ 批量粘贴名单 ]
最近：张三  李四  王五   ← 点一下就切过去

张三  [达标]  带教：小A        已录 12 场 ｜ 最近在练：XD-KL-001 单条口令
日期 2026-10-15 | 空档 | 事件 | 点名 | 口令道具 | 收尾 ▾ |  [保存这一场]
最近记录：日期 / 空档 / 事件 / 点名 / 口令道具 / 收尾 / 运营 / 删除
```

- **30 个主播怎么找**：下拉框支持打字搜索（输入"张"就筛出来）；填一次"只看我带的主播"，只显示你名下的人；最近点过的 6 个主播会出现在"最近"里，一点就切。
- **状态一眼可见**：主播名后面的标签按最近一场算 —— 达标 / 待改进 x/y / 不合格 / 暂无记录。

### 五个省事的点（运营带 30 个主播时最有用）

- **默认只看我带的主播**：填一次自己的名字（记在本机），开关默认打开 —— 下拉里只出现你名下的人；名册里没标归属的历史主播仍会显示，避免"人凭空消失"。
- **一键复制上一场**：懒得重填数字就点它 —— 日期自动换成今天，五个数字照抄上一场，改完点「保存这一场」。
- **按状态分组**：顶部五个圆标签（达标 / 待改进 / 不合格 / **今天没记录** / 还没记录）显示人数，点一下只筛这一组。
- **"今天没记录"当打卡清单用**：点这个标签 → 下拉里只剩今天还没填的人 → 挨个填、保存，**填完的人会自动从列表消失**，一直到清零。
- **键盘操作**：`↑` `↓` 直接上下换主播（`PgUp`/`PgDn` 一次跳 10 个），`回车` 确认并把光标落到"最长空档"输入框，接着就打字。正在输入框里打字时不会抢键，不影响填数字。

下面还会显示一行**今天该盯**（不合格 → 待改进 → 还没记录，并标出缺哪一项、今天有没有记录），点名字直接切过去。

### 怎么把 30 个主播一次加进去

主播页右上角「**批量粘贴名单**」→ 一行一个主播；要指定带教运营就写 `主播名,运营名`：

```
张三
李四,小A
王五,小B
```

重名的自动合并（不重复建人），运营归属也会跟着更新。

### 五个数字（就这五个，拿不准可以留空，留空不算错也不算达标）

| 字段 | 合格线 |
|---|---|
| 最长空档（秒） | ≤2 |
| 每 10 分钟事件 | ≥1 |
| 点名次数 | ≥15 |
| 口令＋道具次数 | ≥10 |
| 收尾四步走完 | 是 |

### 考核只算三项：重在主播成长、每日按时提交、学习

| 指标 | 权重 | 怎么算 |
|---|---|---|
| **主播成长** | 40% | 40% 现状（名下主播本月**所有**场次按赛道合格线的达标率）＋ 60% 变化（每个主播**本月最后一场 vs 第一场**的单场得分；提升 20 分算满分、退 20 分算 0 分） |
| **每日按时提交** | 20% | （当天交的场次 ＋ 事后补交 × 0.5）÷ 应交场次。应交＝**名下主播数 × 4 场/月**（一周一个主播记一场的最低线，不看录像，新装的电脑也能直接算）；**五个分全打**才算一次提交 |
| **学习** | 40% | 课表（月目标 10 条）、资产贡献（2 条）、周复盘（4 次）三项平均 |

两个门禁/口径：

- **抽查门禁**：本月抽查合格率 < 70% → 总分 ×0.8（没抽查不罚也不奖）
- **参与人**：学籍里有带教运营的人也会出现在表里（一场不交就是 0 分不合格，不再“不交就不用考”）

结论：**≥80 达标 ｜ 60–79 待改进 ｜ <60 不合格**（连续两月不合格停带教资格）。

权重量与合作目标写在 `electron/services/incubate.ts` 的 `SCORE_WEIGHTS` / `LEARN_TARGETS`，改数字就能调，无需动其它代码。

### 和拆解联动（教研做一次，运营不用管）

知识库页 → 「从拆解产物导入」→ **选那一场的 `work` 目录**（工具会自动往下找报告，最多 3 层），或者**直接选报告那个 md 文件**。选错目录、选到 memory 那种小文件也不会崩，会告诉你“没抽到东西”。

两种报告都认：

| 报告来源 | 资产从哪抽 | 课表从哪抽 |
|---|---|---|
| v5 指令（本工具自己跑的） | 表单里 `| XD-XX-001 | 类型 | 内容 |` 的行 | `| D1 | XD-XX-001 | 今天练什么 |` 的行 |
| 普通分析报告（含 ChatGPT 跑的） | 「话术库」章节里的表格（场景 + 原句），编号自动生成 XD-HS/KL/DZ/BQ-1xx，带时间戳 | 「可执行 SOP」章节里的编号清单，排成 D1、D2… |

实测（半夏 2026-10-16 那场）：普通报告抽出**资产 19 条 + 课表 11 条**。重复导入不会堆垃圾（同名案例不重复，已有编号会跳过）。

## 七、换一台运营电脑，要注意什么（已核对）

| 项目 | 结论 |
|---|---|
| 安装 | 安装版是**按当前用户安装**（`perMachine: false`），装到 `%LOCALAPPDATA%\Programs\douyin-live-info`，**不需要管理员权限**，和 2.4.9 一样 |
| 依赖 | 自带 Electron 运行时 + 自带 ffmpeg + 自带拆解引擎（`resources\engine`，已确认是干净的 1.2.5），**目标电脑不用装任何东西** |
| 授权 | 授权绑**本机机器码**（Windows MachineGuid）。换电脑要重新激活：把激活页那串机器码发给管理员，拿 `授权_xxx.json` 粘回即可（原有机制，未改动） |
| 数据位置 | 全部在 `%APPDATA%\douyin-live-info\`：弹幕库 `danmu.db`、孵化库 `incubate.db`、AI 设置 `ai.json`、拆解设置 `teardown.json`。**每台电脑各自一份，不互通** |
| 孵化页首次打开 | 名单为空时会提示「点右上角批量粘贴名单」，粘贴后**自动选中第一个主播**，直接就能填 |
| 绝对路径 | 没有。孵化数据只写 userData；v5 指令编进程序；报告模版内置，不依赖任何外部文件 |
| 装新版前 | 先退出正在运行的旧版本（同名 exe 会被占用） |
| 卸载 | 卸载只删程序目录，`%APPDATA%\douyin-live-info` 里的数据会保留（要彻底清就手动删这个目录） |

> 注意：`--user-data-dir` 这类 Chromium 参数**不会**改变 Electron 的 `app.getPath('userData')`，测试时想隔离数据要另想办法（本次测试就是直接落在真实 profile 里，测完已清理）。

**配色以冷为主。** 品牌栏是一条 **深青蓝 → 电光青** 的渐变“律动带”，众艺标志从 34px 提到 **44px**（橙→玫红，是全站唯一的暖色）；「众艺传媒」21px 特粗 +「抖音直播运营工具」16.5px；下面全部收着：冰蓝白底 + 白卡片 + 冷墨字。

**字体：程序自带 Noto Sans SC 可变字体（100–900 全字重，SIL OFL 授权，随安装包一起分发）。** 运营电脑上就算没装任何中文黑体，看到的也是同一副字，不会一台一个样；万一内置字体不可用，会依次回退到系统雅黑。

字阶统一（新页面直接引用变量，不要另写数值）：

| 变量 | 值 | 用在哪 |
|---|---|---|
| `--fs-h1` | 20px / 700 | 页面主标题 |
| `--fs-h2` | 16px | 面板标题 |
| `--fs-h3` | 14px | 卡片/小节标题 |
| `--fs-body` | 13.5px（行高 1.62） | 正文 |
| `--fs-meta` | 12px | 次要说明 |
| `--fs-micro` | 11px | 极小标注 |
| `--font-num` | Bahnschrift | 所有数字/房间号/时长（等宽对齐） |

两个约定，以后加新页面照着走：

1. **冷色 = 可点/选中**（青蓝），**暖色 = 进行中/注意/品牌**（橙、琥珀）。不要再新建第三套强调色。
2. 颜色和字号一律用 `App.vue` 里的 CSS 变量（`--pulse-*` / `--ink-*` / `--line*` / `--fs-*`），不要在页面里写死十六进制和 px。

本次顺手修掉的历史遗留：顶部栏、侧边栏、面板边框被刷成白色（看不见分割线）；`html, body, #app` 里嵌套了 `.boot`、侧边栏页脚里嵌套了 `.version-tag`（CSS 嵌套错位）；孵化页整页还是上一版的深色配色（白字白底、深蓝黑卡片）。
