# 联网更新 / 断点续拆 / 页面简化 —— 实施方案（2026-10-17）

## 一、为什么现在连不上

老板机在路由 A，运营在路由 B，中间隔 NAT；外场地是另一个网。
现在"一键升级"用的是局域网地址（192.168.x.x），**跨路由必然连不上**，这不是 bug，是网络结构决定的。

## 二、更新方案（免费、跨路由、跨场地）

**公网清单 + 直链下载**：

1. 任意免费公网存放点放两个文件：
   - `众艺传媒-抖音直播运营工具 Setup x.y.z.exe`
   - `latest.json`：`{ "version": "x.y.z", "url": "安装包直链", "sha256": "…", "notes": "更新说明" }`
2. App 设置页填一次 `latest.json` 地址（记在本机）
3. 运营点「检查更新」→ 显示版本和说明 →「一键升级」→ 下载（带进度、校验 sha256）→ 静默安装 → 自动重启
4. 以后发版：打包脚本自动生成 `latest.json`，把 exe + json 传上去即可（Gitee Releases / GitHub Releases / 对象存储 / 网盘直链都行）

推荐：**Gitee Releases**（国内快、免费、稳定直链）。
需要一次性准备：Gitee 仓库（公开）+ 私人令牌（只存本机）；之后全自动。

## 三、断点续拆

1. 引擎每一步先检查产物是否存在且比视频新：`index.json` / `grid_*.jpg` / `transcript.json`，有就跳过
2. 停止、失败、更新都不删 `work_场次` 目录
3. 拆解列表给半成品标「未完成·可继续」，点「继续拆解」从断点跑
4. 合并过的分段文件保留，随时可重拆
