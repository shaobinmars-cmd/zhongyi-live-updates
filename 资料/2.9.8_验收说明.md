# 众艺传媒直播运营工具 2.9.8 验收说明

## 安装包

- 安装版：`H:\众艺传媒运营工具\源码\release\众艺传媒-抖音直播运营工具 Setup 2.9.8.exe`
- 便携版：`H:\众艺传媒运营工具\源码\release\众艺传媒-抖音直播运营工具-2.9.8-Portable.exe`
- 升级包副本：`H:\升级包\众艺传媒-抖音直播运营工具 Setup 2.9.8.exe`

本轮只做本机打包，尚未上传 GitHub 发布。

## 本轮新增和修复

1. 拆解页分成“选素材 / 拆解设置与开始 / 运行结果与双场对比”三个区域。
2. 支持直接粘贴线上链接：
   - 抖音直播：按设置的秒数现录一段再拆。
   - 抖音回放、B站、TikTok、快手、小红书等：交给内置 yt-dlp 下载后拆解。
   - 需要登录的平台，要先在浏览器登录；小红书能否下载取决于当前 yt-dlp 对该链接的支持。
3. 图片分析修复：
   - 之前图片请求地址格式写坏，视觉模型实际收不到图。
   - 现在设置页配置千问视觉模型后，拆解页可选择 0 / 4 / 8 张网格图一起分析。
4. BGM 抽样识别：
   - 拆解时抽取最多 4 个时间点，用 Shazam 识别歌名和歌手，写入素材包第六节。
   - 网络或曲库失败只提示，不阻塞素材包生成。
   - 断点续拆会复用 `bgm.json`，不会每次重新识别。
5. 孵化页：
   - 增加“全部主播（批量生成课表）”。
   - 本周课表按周一到周日展开所有主播任务。
   - 案例库记录“来源目录”，案例表可直接打开对应的视频和 AI 报告文件夹。
   - 考核权重统一为：主播成长 40% / 学习 40% / 按时提交 20%。
6. 数据自动同步：
   - 运营机每天自动把孵化库上传到私有 GitHub 数据仓库；关机期间不会传，下次打开软件会自动补传。
   - 老板机可打开“这台是老板汇总电脑”，每天自动生成日报、周报、月报、季报、年报。
   - 设置页可直接手动“立即上传本机数据”和“生成全部报表”。
7. 设置页增加四个快速入口，图片分析已合并进 AI 区域，局域网旧方案收进“高级”折叠区。
8. 仪表盘明确分成“全公司汇总”和“每个直播间汇总”。

## 建议验收顺序

1. 安装 2.9.8，确认能正常打开、授权仍然有效。
2. 设置 → 录制：确认格式 MP4、保存路径正确。
3. 设置 → AI 与图片：保存并测试 AI；图片模型填写千问 Key 后保存。
4. 设置 → 数据与更新：确认运营名字和 GitHub 数据仓库；运营机打开“每天自动上传”，老板机再打开“这台是老板汇总电脑”。
5. 孵化 → 主播跟踪：试一次“添加主播”、选择“全部主播（批量生成课表）”、导入报告。
6. 孵化 → 知识库：案例库选择“案例库（可直接打开视频和报告）”，点“打开文件夹”。
7. 拆解：先试本地视频；再粘贴一个 B 站或抖音回放链接；最后试一场直播链接现录。
8. 双场对比：选 A 对标、B 自家，确认生成的分片每份都不超过上下文预算。

## 注意

- GitHub 数据仓库令牌没有写进安装包，需要在设置页按机器配置，避免把写权限发给无关人员。
- 数据仓库只上传孵化/运营数据和 AI 报告，不上传录像。
- AI Key 只保存在本机配置目录，不进入数据同步快照。
