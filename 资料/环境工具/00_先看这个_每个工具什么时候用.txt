# 环境工具 · 什么时候用哪个

> 前提：**先装好「众艺传媒-抖音直播运营工具」再用这里的工具**（它们靠程序自己的引擎目录干活）。
> 装了哪个版本都行，工具会自动找安装目录，不需要你改里面任何东西。

## 1. 环境自检.bat —— 转写/拆解「没报错但跑不出结果」时

双击运行，会自己弹一个记事本，里面是这台电脑的：CPU / 内存 / 杀毒软件 / 自带 Python / whisper 模型能不能加载。
生成的文件叫 `check-result.txt`，就在这个文件夹里。**把这个文件发给管理员**。

## 2. 环境自检2.bat —— 第 1 个里「加载模型」那步崩了或者卡住时

比第一个查得更细：会换不同参数逐个试加载，并抓 Windows 崩溃记录，定位到底是哪个 dll 崩的。
结果文件 `check2-result.txt`，同样发给管理员。跑一次大约 1 分钟。

## 3. 装GPU加速.bat —— 有 NVIDIA 显卡、想让拆解更快时

会给程序自带的 Python 装 CUDA 库（约 1 GB，走清华镜像，需要联网）。
装完在「拆解」页把设备改成 **GPU**，跑一个任务，日志里出现 `GPU test passed` 就成了。
**没有 NVIDIA 显卡的电脑不要跑这个**，跑了也不会变快。

## 4. VC运行库_先装这个_vc_redist.x64.exe

老电脑缺 VC++ 运行库（`MSVCP140.dll` 版本太旧）会让转写**直接崩掉而且不报错**。
2.5.1 的安装包已经会自己装一遍，只有安装时被跳过、或者后来手动了系统清理，才需要双击它手动补一次。

---

## 两个注意

1. 这几个 .bat 里的注释都是**英文**，这是故意的：cmd 读取 .bat 用的是系统代码页，里面写中文会让它解析出错、直接跑不起来。想改内容请用 VSCode / Notepad++，**不要用记事本另存**。
2. 原来的文件备份在 `_原始备份\` 里（旧版写死了安装目录名，在新版上会报「找不到引擎」，已修成自动查找）。
