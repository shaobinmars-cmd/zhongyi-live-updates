# 众艺传媒运营工具 2.9.12 验收说明

> 状态：已发布到 GitHub Release `v2.9.12`，线上更新清单已切换。

## 本版处理

1. 修复联网更新识别到新版本但下载一直 0%：改为 ghfast / ghproxy / gh-proxy 优先，直连最后，单路 45 秒超时后自动切换。
2. 修复孵化页 AI 报告拖入无反应：支持真实文件路径、file:// 路径和 Markdown/TXT 内容兜底；顶部增加明显拖拽区。
3. 孵化页顶部统一为“添加主播 + 今日该盯 + 当前主播大号标题 + 可折叠基础档案 + 运营加课入口”；基础档案默认只显示关键摘要，展开后才能编辑。
4. 孵化页按“① 主播工作台、② 今日工作、③ 全部课表与记录”分成三个独立区块，分别使用蓝、橙、紫三套边框和标题底色；每块都有大号标题、说明和当前主播提示。
5. 点顶部“今日该盯”中的主播，会自动切换当前主播、档案、计划、评分和下方数据。
6. 本周课表按日期显示不同颜色；点击任一行直接显示课程详情；可切换只看今天该盯与当前主播。
7. 新录入主播即使还没生成计划，也会在本周课表显示“新主播 · 待排课”。
8. 今日五项评分移到当前主播下方，输入后约 0.9 秒自动保存，并显示保存时间。
9. AI 提示词增加强制可落地格式：下一场开播 SOP、下播 30 分钟修正卡、3 天/7 天训练卡、动作编号、负责人、时间次数、验收标准、失败降级和复查时间。
10. 添加主播改成单入口“添加主播（可一次加多人）”，只填姓名即可，名单格式说明简化。
11. 每日数据上传新增“一键自检”。
12. 设置页直接列出 ghfast、ghproxy、gh-proxy 和 GitHub 原文件四个更新入口，点选后可立即检查；程序内部仍会自动回退。
13. 曲库支持 MP3、WAV、M4A、FLAC、AAC、OGG、OPUS、WMA、APE、AIFF、AMR 等常见格式；酷狗加密 .kgm/.kgma/.vpr 不做破解，并给出明确提示。
14. 孵化页重新整理字号和操作层级：页面标题、区块标题、表单标签、正文和提示文字分成清楚的五级；选择主播、生成计划、运营加课、反馈填写各自成组，不再全部挤在一排。
15. 运营自定义计划可修改、可删除；修改保持原记录 ID，不重复，也不会被重新生成 AI 计划覆盖。
16. 主播工作台新增“修改主播资料”：可改主播姓名、带教运营和赛道，改名会同步评分、课表、反馈和培训计划；另设“删除这个错误主播”，仅用于误建或重复建档，二次确认后清理孵化数据，不删除录像、素材包和报告文件。正常离职仍使用“标记离司”，保留姓名并计入离职率。
