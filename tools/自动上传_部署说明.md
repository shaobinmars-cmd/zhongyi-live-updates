# 运营数据自动上传 · 部署说明

## 一、每台运营电脑（一次性，5 分钟）

1. 把 `众艺传媒运营工具\tools\自动上传数据.py` 复制到运营电脑，例如 `C:\众艺\自动上传数据.py`
2. 新建配置文件：`%APPDATA%\douyin-live-info\sync.json`

```json
{
  "owner": "shaobinmars-cmd",
  "repo": "zhongyi-data",
  "token": "（老板单独发给这台电脑的 GitHub 令牌）",
  "operator": "张家宁"
}
```

3. 加每日定时任务（管理员 PowerShell）：

```powershell
schtasks /Create /TN "众艺-数据自动上传" /TR "\"%LOCALAPPDATA%\Programs\douyin-live-info\resources\engine\python-embed\python.exe\" \"C:\众艺\自动上传数据.py\"" /SC DAILY /ST 23:30 /F
```

> 运营电脑没装拆解引擎时，把 `python.exe` 换成安装目录里的：
> `%LOCALAPPDATA%\Programs\douyin-live-info\resources\engine\python-embed\python.exe`
>
> 开发机或老板机从项目目录运行时，使用：
> `H:\众艺传媒运营工具\直播拆解引擎\python-embed\python.exe`

4. 手动测一次：`python 自动上传数据.py`，看到"已上传"即可。

## 二、老板电脑（每天/每周）

```powershell
python 汇总数据.py
```

输出到 `H:\直播运营汇总\`：
- `汇总_日期.json`（所有运营的完整数据）
- `日报_日期.md`（每个运营的主播/计划/反馈/场次条数）

## 三、新增运营/主播

不用改任何配置：
- 新运营：给他一份脚本 + 自己的 `sync.json`，数据自动进汇总
- 新主播：孵化库里新增后，下一次上传自动带上，汇总和报表自动出现

## 四、安全

- 数据仓库是**私有库**（只有老板的令牌能读）
- 每台电脑的令牌只给它自己用；离职直接删对应令牌
- 录像不上传，只传结构化数据（主播档案/计划/反馈/场次/考核）
